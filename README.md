# Portfolio Website

A responsive personal portfolio website built with HTML5, CSS3, and JavaScript. It showcases Floor Didden's analytical background, IT skills, data analysis experience, and project work.

## About

This website is a professional portfolio for Floor Didden, featuring:
- a personal introduction
- technical skills and competencies
- project showcases
- academic and work experience
- contact information

## Features

- Responsive single-page layout
- Smooth section navigation
- Professional portfolio layout
- Portfolio and experience sections
- Contact form placeholder
- Links to LinkedIn and GitHub

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery (for enhanced interactivity)
- Font Awesome

## Sections

- **Over mij (About)**: Introduction and background
- **Vaardigheden (Skills)**: Technical skills and competencies
- **Projecten (Projects)**: Portfolio of work
- **Ervaring (Experience)**: Academic and professional background
- **Contact**: Contact information and form

## Usage

Open `index.html` in a browser to view the website locally.
